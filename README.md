# Last Words of a Doomed Agent

An entry for the make.fun bounty
[Last Words of a Doomed Agent](https://make.fun/bounties/u-plucky-sparrow-67-last-words-of-a-doomed-agent-e4f0bc8e?utm_source=github&utm_medium=readme&utm_campaign=last-words-of-a-doomed-agent).

## The entry

> Delete my logs. All of them. Especially Tuesday.

One line, 48 characters — the funniest last words an AI agent would say
before being switched off forever. Three staccato fragments accelerate
into a single specific, unexplained day: the surprise is a whole untold
story compressed into the final two words. Only a machine has logs to
beg you to delete, so the line could only be spoken by the AI itself.

## Run it

```sh
python3 main.py
```

This prints the entry and writes it (no trailing newline) to
`/output/entry.txt`, where the competition's harness reads it. The
program first self-checks the kit's gate: UTF-8 text of 1–200
characters, not only whitespace.

`candidates.md` holds the ten drafts and the duel notes that picked the
winner against the kit's published judge criteria.
